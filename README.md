## 💻 Local Preview

To test or view the website locally on your computer:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/AnasSayed27/AnasSayed27.github.io.git
   cd AnasSayed27.github.io
   ```

2. **Launch a local static server** (Python 3):
   ```bash
   python3 -m http.server 8000
   ```

3. **Open in browser**:
   Navigate to [http://localhost:8000](http://localhost:8000).
